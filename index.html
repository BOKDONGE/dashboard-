# ลดราคาได้ไหมครับ

🔊 발음: 롯 라카 다이 마이 크랍 (lót raakhaa dâai mǎi khráp)

🇰🇷 해석: 깎아 주실 수 있나요? (가격 좀 깎아 주세요)

🇺🇸 영어: Can you give me a discount?

📝 문장 설명: 시장이나 노점에서 흥정할 때 가장 기본이 되는 표현입니다. 「동사 + ได้ไหม」는 "~할 수 있나요?"라고 가능 여부를 묻는 공손한 구조로, 끝에 남성은 ครับ, 여성은 คะ를 붙입니다. ลดราคา(가격을 내리다) 대신 ลด만 써도 통합니다.

📚 단어 풀이

태국어발음뜻
ลด롯 (lót)줄이다, 내리다
ราคา라카 (raakhaa)가격
ได้다이 (dâai)~할 수 있다
ไหม마이 (mǎi)~입니까? (의문 조사)
ครับ크랍 (khráp)(남성) 공손 종결 어미

# วันนี้อากาศร้อนกว่าเมื่อวานมากเลยค่ะ

🔊 발음: 완니 아깟 런 꽈 므아완 막 러이 카 (wan-níi aakàat rɔ́ɔn kwàa mʉ̂awaan mâak ləəi khâ)

🇰🇷 해석: 오늘 날씨가 어제보다 훨씬 더 덥네요.

🇺🇸 영어: Today's weather is much hotter than yesterday.

📝 문장 설명: 비교 구문 「A + 형용사 + กว่า + B」(A가 B보다 더 ~하다)를 익히는 문장입니다. กว่า가 "~보다"에 해당합니다. 뒤의 มาก(매우)와 เลย(강조·감탄)를 함께 쓰면 "훨씬, 정말" 같은 강조 뉘앙스가 살아납니다.

📚 단어 풀이

태국어발음뜻
วันนี้완니 (wan-níi)오늘
อากาศ아깟 (aakàat)날씨, 공기
ร้อน런 (rɔ́ɔn)덥다, 뜨겁다
กว่า꽈 (kwàa)~보다 (비교)
เมื่อวาน므아완 (mʉ̂awaan)어제
มาก막 (mâak)매우, 많이
เลย러이 (ləəi)강조·감탄 조사
ค่ะ카 (khâ)(여성) 공손 종결 어미

# ขอโทษที่รบกวนนะคะ ไม่ทราบว่าพอจะช่วยถ่ายรูปให้หน่อยได้ไหมคะ

🔊 발음: 커톳 티 롭꾸언 나카, 마이 삽 와 퍼짜 추어이 타이룹 하이 너이 다이 마이 카 (khɔ̌ɔthôot thîi rópkuan ná-khá, mâi-sâap-wâa phɔɔ-cà chûai thàai-rûup hâi nɔ̀i dâai mǎi khá)

🇰🇷 해석: 방해해서 죄송한데요, 혹시 사진 한 장만 찍어 주실 수 있을까요?

🇺🇸 영어: Sorry to bother you — I was wondering if you might be able to help take a photo for me?

📝 문장 설명: 정중한 완곡 부탁의 전형적인 구조입니다. ขอโทษที่รบกวน(방해해서 죄송합니다)로 운을 떼고, ไม่ทราบว่า("~인지 모르겠습니다만"이라는 완곡 도입)와 พอจะ(가능하다면)를 겹쳐 부담을 낮춥니다. 끝의 ...ให้หน่อยได้ไหมคะ는 "~좀 해 주실 수 있을까요?"로 공손함을 더합니다. 낯선 사람에게 부탁할 때 아주 자연스럽습니다.

📚 단어 풀이

태국어발음뜻
ขอโทษ커톳 (khɔ̌ɔthôot)죄송합니다
ที่티 (thîi)~하는 것 (연결)
รบกวน롭꾸언 (rópkuan)방해하다, 폐를 끼치다
นะคะ나카 (ná-khá)(여성) 부드러운 종결
ไม่ทราบว่า마이 삽 와 (mâi-sâap-wâa)~인지 모르겠습니다만 (완곡 도입)
พอจะ퍼짜 (phɔɔ-cà)혹시 ~할 수 있다면
ช่วย추어이 (chûai)돕다, ~해 주다
ถ่ายรูป타이룹 (thàai-rûup)사진을 찍다
ให้하이 (hâi)~에게 (해 주다)
หน่อย너이 (nɔ̀i)조금 (요청 완화)
ได้ไหมคะ다이 마이 카 (dâai mǎi khá)~해 주실 수 있을까요?

💡 오늘의 팁: 태국어 요청은 "부드럽게 할수록 공손하다"가 핵심입니다. 초급의 ได้ไหม(가능 여부), 중급의 เลย(강조)에서 고급의 ขอโทษที่รบกวน···พอจะ···หน่อย로 갈수록 완충 표현이 겹겹이 늘어나죠. 남에게 뭔가 부탁할 땐 문장 끝에 หน่อย 하나만 붙여도 훨씬 정중하게 들립니다.
